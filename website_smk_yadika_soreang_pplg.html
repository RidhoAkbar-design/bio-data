Tentang Jurusan

Profil PPLG SMK Yadika Soreang

Apa itu PPLG?

Pengembangan Perangkat Lunak dan Gim (PPLG) merupakan konsentrasi keahlian modern yang mempelajari cara merancang, membuat, dan memelihara aplikasi web, aplikasi mobile, software desktop, serta game interaktif.

Di SMK Yadika Soreang, program PPLG dirancang berbasis kebutuhan industri era Digital 4.0. Siswa tidak hanya diajarkan koding, tetapi juga pemecahan masalah, kreativitas desain UI/UX, dan kerjasama tim.

Koding & Logika

Menguasai bahasa pemrograman populer.

Game Design

Mengembangkan game 2D & 3D interaktif.

Keunggulan Yadika

Praktek langsung berorientasi proyek nyata (Project-Based Learning) sejak kelas awal.

Visi Jurusan

"Menjadi pusat pendidikan keahlian PPLG unggulan di Jawa Barat yang menghasilkan lulusan berkarakter, berkompeten tinggi di bidang Software & Game Development, serta siap bersaing secara global."

Misi Utama

  • Menyelenggarakan kurikulum terkini sesuai perkembangan teknologi industri IT.
  • Memfasilitasi siswa dengan sarana laboratorium berstandar industri.
  • Membangun sertifikasi keahlian siswa berstandar nasional dan internasional.
Materi Pembelajaran

Kompetensi Keahlian PPLG

Materi komprehensif yang dirancang untuk membekali siswa dengan skill yang paling dicari oleh perusahaan IT saat ini.

Pemrograman Web

Pengembangan website modern frontend & backend menggunakan HTML5, CSS3, JavaScript, Tailwind CSS, React, dan Node.js / PHP Framework.

HTML/CSS JavaScript Laravel/React

Pemrograman Mobile

Membuat aplikasi smartphone Android & iOS menggunakan Kotlin, Flutter, atau React Native dengan integrasi API secara realtime.

Android Studio Flutter REST API

Pemrograman Berbasis Objek

Konsep Object-Oriented Programming (OOP) yang kokoh menggunakan bahasa Java, C#, dan Python untuk logika sistem yang terstruktur.

Java C# Python

Pengembangan Gim (Game Dev)

Merancang mekanisme, karakter, sprite, audio, serta koding logika game 2D dan 3D menggunakan Unity Engine atau Construct.

Unity 3D Construct 3 Game Logic

Basis Data (Database)

Perancangan dan pengelolaan struktur data efisien menggunakan Relational Database (MySQL, PostgreSQL) dan NoSQL (MongoDB).

MySQL PostgreSQL Database Design

UI/UX & Software Design

Merancang antarmuka pengguna yang estetis dan ramah pengguna dengan Figma, wireframing, prototyping, dan metode SDLC.

Figma Prototyping Agile/Scrum

Peluang Karir Lulusan PPLG

Prospek kerja luas di industri digital nasional maupun internasional dengan standar gaji menarik.

Software Engineer

Merancang dan membangun arsitektur perangkat lunak untuk kebutuhan perusahaan dan sistem bisnis.

Web Developer

Mengembangkan situs web interaktif baik dari sisi tampilan (Frontend) maupun sistem backend data.

Mobile App Developer

Spesialis pembuat aplikasi smartphone Android & iOS yang digunakan oleh jutaan pengguna.

Game Developer

Merancang ide, gameplay, logika koding, hingga publikasi game di Google Play Store atau Steam.

Database Administrator

Mengelola keamanan, kecepatan, dan integritas data pada server instansi atau perusahaan.

UI/UX Designer

Merancang pengalaman pengguna dan tampilan visual aplikasi agar nyaman dan mudah digunakan.
